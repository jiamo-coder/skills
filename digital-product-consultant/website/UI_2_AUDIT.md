## P0 实施项

- 使用独立官网平台和 `body` 单一连续滚动，不套用企业后台侧栏或工作顶栏。
- 首屏说明“为谁、解决什么问题”，导航由品牌、五个锚点和一个主 CTA 组成。
- 所有能力、数据和方向有公开来源；不展示客户 Logo、虚构结果、评价、备案或假联系表单。
- 移动导航支持遮罩、`Esc`、导航后关闭和焦点回收；固定导航不遮挡章节标题。
- 320px 至 1440px 重排，支持 200% 缩放、键盘焦点、唯一 H1、语义地标和跳到正文。
- 生产地址确定前 `noindex`；公开前补齐 canonical、robots、sitemap 和 Open Graph。

## P1 实施项

- 使用官网令牌：暖灰画布、青黛紫主色、玉青正向色；朱砂只表达边界或风险。
- 桌面章节间距 96px、紧凑桌面 72px、移动端 56px；正文 15/27px，导语 17/30px。
- 使用编辑式分栏、线性列表和深浅区块建立节奏，不用同权重卡片铺满页面。
- 动效只用于按钮、菜单和焦点反馈；`prefers-reduced-motion` 下移除位移和缩放。
- 不下载远程字体，不运行第三方统计，不在运行时请求外部图片或品牌资源。

## 已确认设计决策

- 身份：成长型 AI 产品经理。
- 主 CTA：查看能力地图。
- 源码：内置于 Skill 的 `website/` 子项目。
- 发布：公开 GitHub Skill 与公开 Sites 生产网址。
- 验收：1440、1200、1024、760、390、320px，外加 200% 缩放与键盘流程。
